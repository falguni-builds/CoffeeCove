# CoffeeCove
# ☕ CoffeeCove - Coffee Shop Landing Page

This repository contains **CoffeeCove**, a responsive coffee shop landing page developed using **HTML and CSS**.

The project was created to practice frontend development, responsive design, website layout, UI design, and creating an attractive café-themed user interface.

## Features

* Fixed navigation bar
* Hero section
* About Us section
* Coffee and dessert menu
* Product cards with prices
* Why Choose Us section
* Customer reviews
* Contact section
* Responsive layout
* Custom food and coffee images
* Clean and modern UI
* Smooth navigation using anchor links

## Technologies Used

* HTML5
* CSS3
* VS Code
* Live Server

## Website Sections

### 1. Home

An attractive hero section introducing CoffeeCove with a call-to-action button to explore the menu.

### 2. About Us

Provides information about CoffeeCove and its coffee experience.

### 3. Menu

Displays different coffee and dessert items including:

* Espresso
* Latte
* Cold Brew Coffee
* Cappuccino
* Caramel Macchiato
* Mocha Delight
* Chocolate Brownie
* Blueberry Cheesecake

### 4. Why Choose Us

Highlights CoffeeCove's features such as premium coffee, expert baristas, fast service, and free Wi-Fi.

### 5. Reviews

Displays customer reviews and ratings.

### 6. Contact

Contains café location, phone number, email address, and opening hours.
